# polyfillme v1.0.8 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `release/1.0.8`

---

## Overview

polyfillme is relicensed from MIT to the Apache License 2.0. The repository now carries the full license text, and the README is reorganized around a What's New section backed by per-version changelogs for every release so far. No runtime code changed.

---

## ⚖️ License

### Relicensed under Apache-2.0 ([#56](https://github.com/CLDMV/polyfillme/pull/56))

`package.json` `license` changes from `MIT` to `Apache-2.0`, and a `LICENSE` file with the full Apache License 2.0 text is added at the repository root (previously there was no license file). Apache-2.0 keeps the permissive terms of MIT and adds an explicit patent grant and patent-retaliation clause, and asks redistributors to keep the license text and mark files they changed.

## 📚 Documentation

- **NEW:** [docs/changelog/v1/](./) — release notes for every version from [v1.0.0](./v1.0.0.md) through this one.
- **NEW:** [docs/changelog/v1/v1.0.8.md](./v1.0.8.md) — this changelog.
