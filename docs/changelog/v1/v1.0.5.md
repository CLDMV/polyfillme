# polyfillme v1.0.5 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

Dependency and CI maintenance, plus one small runtime change: the errors polyfillme throws for glob, read and parse failures now keep the original error as `cause`.

---

## 🐛 Bug Fixes

### Thrown errors keep their cause

When resolving a glob, reading a file or parsing a file fails, polyfillme throws a new `Error` with a descriptive message. That error now carries the underlying error as `err.cause`, so callers can inspect the original stack and code. The messages are unchanged.

- CI matrix raised for Vitest 5: minimum Node.js 22.12.0, maximum major 26 ([#34](https://github.com/CLDMV/polyfillme/pull/34)).
