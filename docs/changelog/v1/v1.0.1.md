# polyfillme v1.0.1 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

Moves polyfillme onto the CLDMV v4 release flow and the `@cldmv/vitest-runner` test setup, and fixes the module failing to load on a clean install. The public API is unchanged.

---

## 🐛 Bug Fixes

### Module loads on a clean install ([#3](https://github.com/CLDMV/polyfillme/pull/3))

`src/lib/polyfillSources.js` required `node-fetch`, which was never declared as a dependency, so `require("polyfillme")` threw `MODULE_NOT_FOUND`. It now uses the global `fetch` built into Node.js 18 and later. The Cloudflare source (`source: "cloudflare"`) is the only path that fetches.

## 🔧 CI & tooling

- Onboarded to the CLDMV v4 staging-branch workflows (`next` / `hotfixes` → `master`, release PRs, publish, CodeQL, Scorecard, dependency review) ([#3](https://github.com/CLDMV/polyfillme/pull/3)).
- Tests moved from Jest to Vitest through `@cldmv/vitest-runner` with coverage; `npm test`, `npm run coverage` and `npm run ci:coverage` replace the bare `jest` script ([#3](https://github.com/CLDMV/polyfillme/pull/3)).
- The workflow default branch was set to `master` after the repository's default branch was renamed from `main` ([#5](https://github.com/CLDMV/polyfillme/pull/5)).
- `.github/` is no longer git-ignored, so the workflows are tracked.

## 🔧 Dependencies

- Removed `jest` (dev); added `vitest`, `@vitest/coverage-v8` and `@cldmv/vitest-runner` (dev).
- `flatted` 3.3.3 → 3.4.4 (dev, transitive) ([#7](https://github.com/CLDMV/polyfillme/pull/7)).

---

## Upgrade notes

- No breaking changes — drop-in for v1.0.0, which could not be loaded without manually installing `node-fetch`.
- Requires a Node.js version with a global `fetch` (18 or later).
