# polyfillme v1.0.4 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

Security and dependency release. It patches two transitive advisories and upgrades the `espree` parser from 9 to 11. The parser upgrade raises the Node.js versions polyfillme can install on, which is a breaking change for older runtimes despite shipping as a patch. The repository also gains its lint and format setup.

---

## 💥 Breaking Changes

### Node.js floor raised by `espree` 11 ([#20](https://github.com/CLDMV/polyfillme/pull/20))

`espree`, polyfillme's runtime parser, moved from 9.6.1 to 11.2.0. `espree` 11 declares `engines.node` as `^20.19.0 || ^22.13.0 || >=24` (9.6.1 accepted Node.js 12.22 and later), so this version, despite being a patch, no longer supports Node.js 18, 20 before 20.19, or 22 before 22.13. polyfillme itself still parses scanned files with `ecmaVersion: 2020`, so detection results do not change.

## 🔒 Security & supply chain

- `picomatch` 2.3.1 → 2.3.2, reached at runtime through `fast-glob` → `micromatch` (GHSA-3v7f-55p6-f55p, GHSA-c2c7-rcm5-vvqj) ([#20](https://github.com/CLDMV/polyfillme/pull/20)).
- `nanoid` 3.3.16 → 3.3.18, dev-only through `vitest` (GHSA-2v37-7h3g-55p8) ([#20](https://github.com/CLDMV/polyfillme/pull/20)).
- `npm audit` reports no vulnerabilities after this release.

## 🔧 CI & tooling

- Added `lint`, `lint:fix`, `format` and `format:check` scripts for the post-merge lint/format autofix ([#20](https://github.com/CLDMV/polyfillme/pull/20)).
- Adopted the canonical CLDMV ESLint and Prettier config under `.configs/` with JSONv, Markdown, CSS and JSON support, and a `.prettierignore` that keeps workflow YAML and generated data out of Prettier ([#21](https://github.com/CLDMV/polyfillme/pull/21)).
- Restored workflow YAML that an autofix run had reformatted before the ignore file existed ([#22](https://github.com/CLDMV/polyfillme/pull/22)).

## 🔧 Dependencies

- `espree` 9.6.1 → 11.2.0 (runtime) ([#20](https://github.com/CLDMV/polyfillme/pull/20)).
- `eslint` 9 → 10.8.1, `@eslint/json` 0.13 → 2.0.1, `@mdn/browser-compat-data` 6 → 8.0.10 (dev) ([#20](https://github.com/CLDMV/polyfillme/pull/20)).
- `prettier` 3.6.2 → 3.9.6 (dev) ([#14](https://github.com/CLDMV/polyfillme/pull/14)).

## Upgrade notes

- Run polyfillme on Node.js `^20.19.0`, `^22.13.0` or `>=24`. On older versions, stay on [v1.0.3](./v1.0.3.md).
- The API is unchanged.
