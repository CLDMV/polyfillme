# polyfillme v1.0.9 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Dev-dependency release with one security update to a transitive development package. **No runtime code changed.** The net change against v1.0.8 is `package.json` (the version and nine `devDependencies` ranges) and the lockfile. `src/`, including the generated `src/data/mdn/mdn.json`, is unchanged; the runtime dependencies (`espree`, `fast-glob` and `polyfill-library`) have identical ranges and identical locked versions. polyfillme declares no `engines.node`, and nothing in this release changes what the package needs at runtime.

---

## 🔒 Security

### `brace-expansion` 5.0.9 → 5.0.12 ([#64](https://github.com/CLDMV/polyfillme/pull/64))

`brace-expansion` before 5.0.12 spends quadratic time on input shaped like `{a},b}`: each literal `}` triggers another full re-scan, so a pattern of about 128 KB can block the event loop for roughly half a minute ([GHSA-q2hr-2g5m-vwhr](https://github.com/advisories/GHSA-q2hr-2g5m-vwhr), CVE-2026-102277, CWE-407, medium severity, CVSS 5.3). The fix bounds the number of rewrite passes.

In this repository the package is a development-only transitive dependency, reached through `minimatch` in the lint and test toolchain, and it is flagged `dev` in the lockfile. It is not part of the installed runtime dependency tree, so users of polyfillme were not exposed; the bump clears the alert for contributors and CI.

## 🔧 CI & tooling

### `@cldmv/vitest-runner` 1.5.3 raises its own Node.js floor ([#70](https://github.com/CLDMV/polyfillme/pull/70))

`@cldmv/vitest-runner` 1.5.1 → 1.5.3 now declares `engines.node` `>=22.12.0` (it was `>=20.19.0`), and its `chalk` dependency moves from a nested 5.6.2 to a top-level 6.0.1, which requires Node.js 22 or newer. This only affects people who run this repository's test suite. The CI matrix already starts at Node 22.12.0 because `vitest` 5 requires `^22.12.0 || ^24.0.0 || >=26.0.0`, so CI is unaffected, and contributors need Node.js 22.12 or newer to run the tests.

### `vitest` 5.0.3 and `eslint` 10.12.0 ([#65](https://github.com/CLDMV/polyfillme/pull/65), [#66](https://github.com/CLDMV/polyfillme/pull/66))

`vitest` 5.0.2 → 5.0.3 (with `@vitest/coverage-v8`, `@vitest/mocker` and `@vitest/spy` locked at 5.0.3, `vite` 8.3.1 → 8.3.2 and `rolldown` 1.2.11 → 1.2.12) and `eslint` 10.11.0 → 10.12.0. Their Node.js ranges are unchanged.
