# polyfillme v1.0.3 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

CI-only release. No runtime code changed. This version has no git tag; the release commit on `master` is `522c92c`.

---

## 🔧 CI & tooling

- CI runs on `next`, `hotfixes` and release PRs now use a unique concurrency group per run, so a newer push no longer cancels a release-relevant run and leaves the release PR with a cancelled check; feature branches still cancel superseded runs ([#12](https://github.com/CLDMV/polyfillme/pull/12)).

## Upgrade notes
