# polyfillme v1.0.6 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Tooling and dependency release. Every source file gains the standard CLDMV file header, the workflows are synced with the current CLDMV templates, and the test toolchain moves to Vitest 5. The only change to runtime files is the added header comment.

---

## 🔧 CI & tooling

- Workflows synced with the CLDMV/.github v4.29.2 templates ([#44](https://github.com/CLDMV/polyfillme/pull/44)).
- Added the bundle-size workflow, measuring the published top-level entry files, and restored the full release-merge workflow list ([#45](https://github.com/CLDMV/polyfillme/pull/45)).
- A skipped pull-request run of the in-repo PR mirror job no longer satisfies the required `✅ Required PR Check` ([#51](https://github.com/CLDMV/polyfillme/pull/51)).
- Adopted the shared CLDMV `@cldmv/fix-headers` config (`npm run fix:headers`) and stamped uniform file headers across the source and tests ([#50](https://github.com/CLDMV/polyfillme/pull/50)).

## 🔧 Dependencies
